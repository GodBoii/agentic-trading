# Trader's Control API

These set of APIs are built for traders to manage their risks and preferences using advanced tools built right into Dhan. You can set and manage Kill Switch for your account along with having a daily P&L based auto-exit feature.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/killswitch` | Manage Kill Switch |
| GET | `/killswitch` | Kill Switch Status |
| POST | `/pnlExit` | Configure P&L Based Exit |
| DELETE | `/pnlExit` | Stop P&L Based Exit |
| GET | `/pnlExit` | Get P&L Based Exit |

---

## Manage Kill Switch

This API lets you activate the kill switch for your account, which will disable trading for the current trading day. You can pass query parameter `killSwitchStatus` as `ACTIVATE` or `DEACTIVATE` to manage Kill Switch settings.

> **Note:**
> You need to ensure that all your positions are closed and there are no pending orders in your account to be able to activate Kill Switch.

### Request

```bash
curl --request POST \
--url 'https://api.dhan.co/v2/killswitch?killSwitchStatus=ACTIVATE' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'access-token: JWT'
```

### Request Structure
*No Body*

### Response Structure

```json
{
    "dhanClientId":"1000000009",
    "killSwitchStatus": "Kill Switch has been successfully activated"
}
```

### Parameters

| Field | Type | Description |
|---|---|---|
| dhanClientId | string | User specific identification generated by Dhan |
| killSwitchStatus | string | Status of Kill Switch - activated or not |

## P&L Based Exit

The P&L Based Exit API allows users to configure automatic exit rules based on cumulative profit or loss thresholds. When the defined limits are breached, all applicable positions are exited and open orders cancelled.

> **Note:**
> The configured P&L based exit remains active for the current day and is reset at the end of the trading session.

### Request

```bash
curl --request POST \
  --url https://api.dhan.co/v2/pnlExit \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'access-token: JWT' \
  --data '{Request Body}'
```

### Request Structure

```json
{
    "profitValue": "1500.00",
    "lossValue": "500.00",
    "productType": ["INTRADAY", "DELIVERY"],
    "enableKillSwitch": true
}
```

### Request Parameters

| Parameter | Data Type | Description |
|---|---|---|
| profitValue | float | User-defined target profit amount for the P&L exit |
| lossValue | float | User-defined target loss amount for the P&L exit |
| productType | array[string] | Product types applicable for the P&L exit (e.g. `INTRADAY`, `DELIVERY`) |
| enableKillSwitch | boolean | Indicates if the kill switch is enabled for this P&L exit |

### Response Structure

```json
{
    "pnlExitStatus": "ACTIVE",
    "message": "P&L based exit configured successfully"
}
```

### Response Parameters

| Parameter | Data Type | Description |
|---|---|---|
| pnlExitStatus | string | Status of P&L Based Exit: `ACTIVE`, `INACTIVE` |
| message | string | Status description of Conditional Trigger |

> **Warning:**
> In case `profitValue` is set below the current profit in P&L, then the P&L based exit will be triggered immediately. This applies to `lossValue` set above the current loss in P&L as well.

## Stop P&L Based Exit

Disable the active P&L based exit configuration.

### Request

```bash
curl --request DELETE \
  --url https://api.dhan.co/v2/pnlExit \
  --header 'Accept: application/json' \
  --header 'access-token: JWT'
```

### Request Structure
*No Body*

### Response Structure

```json
{
    "pnlExitStatus": "DISABLED",
    "message": "P&L based exit stopped successfully"
}
```

### Response Parameters

| Parameter | Data Type | Description |
|---|---|---|
| pnlExitStatus | string | Status of P&L Based Exit: `DISABLED`, `ACTIVE` |
| message | string | Status message confirmation |

## Get P&L Based Exit

Fetch the currently active P&L based exit configuration for the current trading day.

### Request

```bash
curl --request GET \
  --url https://api.dhan.co/v2/pnlExit \
  --header 'Accept: application/json' \
  --header 'access-token: JWT'
```

### Request Structure
*No Body*

### Response Structure

```json
{
    "pnlExitStatus": "ACTIVE",
    "profit": "1500.00",
    "loss": "500.00",
    "productType": ["INTRADAY", "DELIVERY"],
    "enable_kill_switch": true
}
```

### Response Parameters

| Parameter | Data Type | Description |
|---|---|---|
| pnlExitStatus | string | Current status of the P&L exit operation: `ACTIVE`, `INACTIVE` |
| profit | float | User-defined target profit amount for the P&L exit |
| loss | float | User-defined target loss amount for the P&L exit |
| enable_kill_switch | boolean | Indicates if the kill switch is enabled for this P&L exit |
| productType | array[string] | Product types applicable for the P&L exit |

---

**Note:** For description of enum values, refer [Annexure](https://dhanhq.co/docs/v2/annexure)
