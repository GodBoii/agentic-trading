The candle rule uses observed quote-midpoint extremes. Missing exchange ticks can change wick classification, and no true trade-volume bar is available. Completed bars release only when a later-minute quote arrives. A next-observation aggressive fill is a sensitivity assumption; it does not demonstrate queue fill, top-level executable size or exchange latency.

Strict mode's zero trades reflect missing or old metadata and broken continuous history. Proxy mode permits unknown freshness metadata explicitly, so these losses are recorded-tape diagnostics. Neither mode establishes live suitability. All sessions had been seen by earlier research; the validation label is organizational, not an untouched holdout.
