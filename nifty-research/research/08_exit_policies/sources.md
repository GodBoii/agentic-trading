# Sources read on 1 October 2026

- [Carr and Lopez de Prado, Determining optimal trading rules without backtesting](https://arxiv.org/abs/1408.1159). The original paper addresses stop/target calibration and overfitting under a specified discrete Ornstein-Uhlenbeck process. Its assumptions do not establish that Nifty option premiums follow that process. This study predeclares simple thresholds and does not implement or claim to replicate the paper's optimal rule.
- [Lipton and Lopez de Prado, A closed-form solution for optimal mean-reverting trading strategies](https://arxiv.org/abs/2003.10502). Original analytical work on profit, loss and time boundaries for an OU model. Used to frame exit decisions as a stopping-time problem with a maximum horizon, rather than selecting a single future exit timestamp.
- [Backtesting.py order processing implementation](https://github.com/kernc/backtesting.py/blob/master/backtesting/backtesting.py). Primary implementation inspected for order semantics and intra-bar ambiguity. A stop trigger is distinct from its eventual execution price. This study uses a custom quote replay and does not run backtesting.py or copy its code.
- [Backtesting.py maintainer explanation of stop/target ordering](https://github.com/kernc/backtesting.py/discussions/242). Primary maintainer response concerning both stop and target in the same OHLC bar. It supports treating assumed intrabar ordering as a modelling choice, not an observed fact.
- [VectorBT portfolio API](https://vectorbt.dev/api/portfolio/base/). Official documentation inspected for stop priority, per-symbol per-bar action limits and shifting close-derived signals forward. This study instead delays entries and exits by one second and monitors a chronological quote clock. VectorBT is not installed or benchmarked.

The cost model and quote structures come from [study 04](../04_options_hedging/sources.md) and the shared lab configuration. Only primary research, official documentation and original repository authors inform this experiment.
