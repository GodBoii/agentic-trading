# Baseline experiment

The first completed depth forecast and directional option replay is preserved here. `artifacts/report.md` contains the original output, and `findings.md` records the conclusions. `source_snapshot` preserves the original implementation and matches its recorded package hashes. It is an archival snapshot, not a standalone installed package. Shared readers and tools remain in `../../nifty_lab`.

From nifty-research, run `python -m nifty_lab evaluate`, `python -m nifty_lab replay` and `python -m nifty_lab report`. The default output location is now this study's artifacts directory. Original source recordings remain in python-backend. Provenance paths inside the original historical manifest can refer to the previous artifacts location; the recordings themselves were not moved.

The first experiment found no validated profitable policy. Later studies must not claim these already examined dates are untouched confirmation.
